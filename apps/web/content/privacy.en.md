# Privacy

*Draft. The game team is preparing the final text.*

This site shows miniatures that players shared from the game Miniature Workshop. We keep only what the site needs to work.

## What we store

When you press "Share" in the game, the server receives:

- the 3D model of the miniature and its card from photo mode;
- the title, description and workshop name you entered in the game;
- data about the miniature from the game: faction, parts, paints, stroke count, work time, appraisal, game version;
- the stroke journal. It is private: the site never shows it or serves it to anyone;
- a fingerprint (hash) of the upload key the game creates on your computer. We do not store the key itself;
- your Steam ID, if the game sent it. It is not verified and is not shown anywhere.

When someone reports a miniature, we store the reason and the text of the report.

## IP addresses

We store an IP address only as a hash with a secret salt. It is needed to limit uploads and reports from one address and to block abusers. IP addresses are not written to server logs.

## Cookies and trackers

The site has no third-party trackers and no ads. It sets one cookie with the interface language you chose. That cookie is technical, so there is no cookie banner.

## What others can see

Everything you share is public: the miniature page, the workshop page and the gallery are open to anyone, and the 3D model and the card can be downloaded. Do not put anything in a title, description or workshop name that you would not show to everyone.

## Deletion

At the owner's request we delete a miniature or a whole workshop together with its files. An empty record with the identifier stays in the database so that the same link is never given to another miniature.
