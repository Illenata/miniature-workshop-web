# Перевірки в браузері

Playwright-сценарії, якими перевіряється кожен крок: вони відкривають сайт на ширині телефона (360 px) і на десктопі,
натискають кнопки й звіряють результат зі сторінкою, базою та сховищем. Кожен рядок виводу — `PASS` або `FAIL` з
назвою перевірки. Скриншоти лягають у `e2e/.out/` (у git не потрапляють).

Це не тест-раннер і не CI: сценарії ганяються вручну проти запущеного сайту й **змінюють дані в базі** (ховають,
видаляють, банять, чистять сесії й журнал адмінки). Запускай їх лише на локальній базі з сідом.

## Що потрібно

- Запущені API (`:3000`) і сторінки (`:5173`), база й сховище з сідом: `npm run seed -- --count 300 --reset`.
- `psql` у PATH (сценарії читають і правлять базу напряму).
- Node 22.18+ і встановлений Playwright:

```bash
cd e2e
npm install
npx playwright install chromium
```

## Запуск

```bash
cd e2e
node check.mjs      # галерея: сітка, фільтр, «Показати ще», мова, телефон і десктоп
node check3d.mjs    # режим 3D: не більше 4 glb одночасно, постери
node sort.mjs       # сортування галереї
node mpage.mjs      # сторінка мініатюри, OG-теги, перегляди, схована → 404
node report.mjs     # скарги; три скарги ховають мініатюру
node coll.mjs       # сторінка колекції, QR, забанена → 404

# адмінка: потрібен пароль, з якого зроблено ADMIN_PASSWORD_HASH у .env
E2E_ADMIN_PASSWORD=... node admin1.mjs   # вхід, TOTP, сесії, вихід
E2E_ADMIN_PASSWORD=... node admin2.mjs   # «Мініатюри»: вкладки, «Сховати / Показати»
E2E_ADMIN_PASSWORD=... node admin3.mjs   # «Видалити», бан і розбан колекції
```

Кожен сценарій адмінки розрахований на свіжий сід і на рестарт API перед запуском (ліміт спроб входу живе в пам'яті
сервера). `report.mjs` ховає мініатюру, тож повторний запуск без сіду дасть `FAIL`. Відомий хибний `FAIL console clean`
у `report.mjs` — це очікуваний 404 документа схованої мініатюри.

## Налаштування

Усе береться зі змінних середовища, а якщо їх немає — з `.env`, потім з `.env.example` у корені репозиторію.

| Змінна | За замовчуванням | Що це |
| --- | --- | --- |
| `E2E_BASE_URL` | `http://localhost:5173` | сайт |
| `E2E_API_URL` | `http://127.0.0.1:3000` | API |
| `E2E_DATABASE_URL` | `DATABASE_URL` з `.env` | база для `psql` |
| `E2E_S3_URL` | `S3_ENDPOINT/S3_BUCKET` | бакет; перевірка розраховує, що анонімний GET дає 403 для наявного файла й 404 для стертого (так відповідає moto; якщо сховище відповідає інакше, перевірки файлів в `admin3.mjs` дадуть `FAIL`) |
| `E2E_ADMIN_PASSWORD` | — | пароль адміна, лише для `admin*.mjs` |
| `ADMIN_TOTP_SECRET` | з `.env` | секрет TOTP, сценарій сам рахує код |
| `E2E_CHROMIUM` | Chromium від Playwright | шлях до іншого Chromium |
| `E2E_OUT` | `e2e/.out` | куди класти скриншоти |
